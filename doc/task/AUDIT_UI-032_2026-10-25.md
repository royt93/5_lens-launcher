# Audit UI-032 — Lens manager process death, main-thread prefs và edge-to-edge

Ngày: 2026-10-25. Branch `dev`. Base `79b2f28a`.
Thiết bị: TECNO BG6 `118743744X002560`, Android 13 (`ro.build.version.release=13`), user 0 (device locked cho toàn bộ phiên).

## Vấn đề

`LensManagementActivity.onSaveInstanceState` chỉ lưu `STATE_EDITING` và `STATE_SELECTED`; dialog đổi tên lens / tạo nhóm / chọn nhóm / xác nhận xóa bị dismiss ở `onDestroy`, không được khôi phục sau Activity recreation. Dialog nhập tên mất draft. `settings.getCollapsedLensGroups()` bị gọi ba lần ở các đường nạp/cập nhật group trên main thread.
Owner còn nhắc lỗi edge-to-edge: Activity targetSdk 37 không có insets listener; toolbar bị status bar/cutout che, hàng cuối và thanh hành động nhóm bị gesture bar che.

## Thay đổi

1. **State restoration (`LensManagementActivity.kt`):**
   - Lưu `activeDialogKind`, `draftText`, `targetLensId` vào `Bundle` khi dialog đang hiển thị.
   - Sau khi Room tải lenses, khôi phục dialog rename/delete theo `targetId`, dialog create group theo selection đã lưu, và assign picker theo selection.
   - Giữ `android.R.id.edit`, đặt cursor cuối draft khi khôi phục.
   - Thêm test hooks nhỏ (`showCreateGroupDialogForTest`, `showRenameLensDialogForTest`, `lensGroupDialogForTest`) để test không dùng reflection private.
2. **Collapsed groups cache:**
   - Nạp `cachedCollapsedGroups` một lần trong `onCreate`.
   - Adapter callback cập nhật cache và prefs; mọi `submit()`/reload dùng cache thay vì đọc SharedPreferences lặp lại trên main thread.
3. **Edge-to-edge/insets:**
   - Gọi `WindowCompat.setDecorFitsSystemWindows(window, false)` rõ ràng.
   - Listener root lấy `systemBars | displayCutout`; cộng insets top vào AppBar, bottom vào RecyclerView và group action bar, side vào root.
   - Padding mỗi lần tính từ base padding chụp lúc khởi tạo cộng inset hiện tại, không tích lũy khi dispatch lặp.
   - Bỏ `setDecorFitsSystemWindows(window, true)` deprecated trong `onDestroy`; gỡ listener khi Activity destroy.
4. **Fixture an toàn cho Room (`LensManagerRoomSnapshot.kt`):**
   - Snapshot cả `LENS_WORKSPACE`, toàn bộ hàng `APP_PERSISTENT`, và `sqlite_sequence`.
   - Khôi phục chính xác trạng thái ban đầu sau mỗi test; kiểm chứng `diff -u` dump SQLite trước và sau test trả về 0 dòng khác biệt.

Reading: per-frame cost does not rise and there is no jank. The only cost is the NUMBER of frames: while an icon waits out the 200 ms dwell
and grows for 150 ms, the view asks for a frame every vsync (postInvalidateOnAnimation). It stops once the icon is fully grown
(frames per 0.5 s on-1: 29 18 6 34 31 2 1 2 1, then ~1-2). Removing that redraw leaves the icon stuck at 1x (mutation caught by LensViewHoverMagnifySelfRedrawTest).

Limits: one device, one adb scenario; frame counts depend on how long the finger rests. The first trace attempt was discarded because a loop variable clash
overwrote labels and every run ended with an ad on screen; this set was recaptured with the fix and an ad check before each run.

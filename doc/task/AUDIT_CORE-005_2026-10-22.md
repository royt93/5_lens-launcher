Ngày: 2026-10-22. Branch `dev`, base `59df24e0`. Pixel 7 Pro `2B051FDH3006MU`, Android 17, build `16269273` (owner đổi từ S24 Ultra sang Pixel trong phiên).

## Thay đổi cuối

- `UtilSettings` thêm `KEY_ICON_PACK_PACKAGE_NAME`, empty string đại diện system pack và migration từ `KEY_ICON_PACK_LABEL_NAME`.
- Legacy default sentinel migrates sang package identity rỗng; label chỉ migrate nếu đúng một installed pack khớp. Missing/ambiguous legacy label được giữ nguyên để retry sau.
- `UtilApp.getAppShells` và `loadSingleAppIcon` resolve bằng `mPackageName`; cache token package+version, không dùng display label.
- Settings dialog tách display label/package value; khi chọn lưu packageName. Settings summary resolve catalog label, missing package giữ legacy label, system identity hiển thị translated default.
- `TaskUpdateApps` truyền package identity vào full loader.
- Không đổi per-lens scope hoặc icon rendering.

## Thay đổi

- `UtilSettings` thêm `KEY_ICON_PACK_PACKAGE_NAME` và default identity `""` cho system icons.
- `iconPackPackageName(catalog)` ưu tiên package identity; nếu chưa có thì migrate legacy default sentinel sang empty identity, hoặc label chỉ khi catalog có đúng một pack khớp. Legacy label không ánh xạ được/ambiguous được giữ để thử lại sau.
- `UtilApp.getAppShells` và `loadSingleAppIcon` resolve pack bằng `mPackageName`, cache token chỉ gồm packageName + version token; tên hiển thị không tham gia identity/key.
- Settings dialog tách display names khỏi packageName values, selection index theo packageName, lưu packageName khi chọn và giữ legacy label cho migration/backward-compatible display. `FrmSettings` hiển thị catalog label nếu pack tồn tại, label legacy nếu package unavailable, hoặc system default khi identity rỗng.

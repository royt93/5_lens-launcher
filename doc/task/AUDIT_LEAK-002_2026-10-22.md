# Audit LEAK-002 — LensView stale selection and callbacks

Date: 2026-10-22. Branch `dev`, base `5f27f1a2`. Locked device: Samsung S24 Ultra `R5CX613VZBR`, model `SM-S928B`, Android 17, build `S928BXXU6EZIF`.

## Changes

- `launchApp()` returns if `mPackageManager` absent or `mApps?.getOrNull(mSelectIndex)` is null. Valid launch still uses same app, bounds and `UtilApp.launchComponent` arguments.
- `drawAppName()` returns if selected index no longer maps to an app; draws label from resolved `app` otherwise.
- `onDetachedFromWindow()` now nulls `onCurvatureAdjustedListener`, `onEmptySpaceLongPressListener`, `onSearchSwipeDownListener` alongside existing haptic/edge/vibrator cleanup.
- Removed `shouldAllowAppLaunch` helper and its call. Pinch and pinch-release branches return before normal ACTION_UP path; existing pinch integration suite remains green.
- No animation, user gesture, or UI design changes.

## RED/GREEN

- `LensViewStaleSelectionIntegrationTest` has two focused cases. Baseline RED on S24 reproduced `IndexOutOfBoundsException` in `drawAppName` at `list[mSelectIndex]` and `launchApp` at same invalid index. Candidate both pass.
- `LensViewReattachIntegrationTest.detachingClearsAllCallbacksThatCouldRetainTheActivity`: baseline RED at `onCurvatureAdjustedListener` non-null after real `host.removeView`; candidate nulls all six and test passes including reattach check.
- `LensViewPinchIntegrationTest` 12/12 pass. Removed stale unit helper test which asserted only pure guard; integration path still covers pinch-release state.
- During test development, a real-window hide-animation harness did not start/finish reliably on S24, and framework `Animation` internals could not expose its listener (`NoSuchFieldException: mListener`). I stopped that route. The final regression invokes the actual private label/launch methods with a valid-then-stale selection and invokes animation callback only on an unsuccessful prototype that was not kept. Final tests do not claim end-to-end touch→hide timing. This is a material coverage limit versus original AC wording.

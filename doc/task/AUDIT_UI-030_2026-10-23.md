# Audit UI-030 — Ẩn/khóa app ở Home list mode không đồng bộ lưới

Ngày: 2026-10-23. Branch `dev`. Base `f2aa4287`.
Thiết bị: Google Pixel 7 Pro `2B051FDH3006MU`, Android 17, user 0 (owner đổi khóa từ S24 Ultra vì S24 mất kết nối adb).

## Vấn đề (đã xác minh trong code)

`AppAdapter` dùng chung cho `ActSettings` và list mode của `ActHome`. `sendChangeAppsVisibilityBroadcast()` / `sendChangeAppsLockBroadcast()` chỉ gửi khi `mActivityContext instanceof ActSettings`, nên ở Home list mode bấm ẩn/khóa không phát sự kiện nào và `ActHome` không gọi lại `assignApps()` qua observer `visibilityChanged`/`lockChanged`. Ngoài ra broadcast được phát TRƯỚC khi toggle: với khóa, còn trước cả bước xác thực biometric (có thể bị hủy).

## Thay đổi

`adt/AppAdapter.java`, `adt/AppRowActions.kt`:
- Xóa hai hàm gửi broadcast bị chặn theo `ActSettings` và hai lệnh gọi trước toggle; gỡ import `ActSettings` thừa.
- Thêm `AppRowActions` xử lý persistence + event cho visibility, lock, organization; `AppViewHolder` chỉ gọi helper và cập nhật UI. Khóa vẫn qua `Biometric.toggleLockApp`; callback chỉ ghi và phát event sau auth thành công.
- Callback giữ nguyên `App`/lens ban đầu cho persistence; nếu holder đã bind sang row khác khi prompt hoàn tất, bỏ cập nhật UI row mới.
- Không đổi `bulkSetVisibility` (vẫn dùng broadcast tới receiver).

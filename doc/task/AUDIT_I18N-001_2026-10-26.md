Date: 2026-10-26. Branch `dev`, base SHA `cba32194` (working tree, chưa commit). Device policy: Samsung S24 Ultra `R5CX613VZBR` (SM-S928B, Android 17 / API 37) do owner chọn tường minh trong phiên. Không dùng BG6/KJ7/Pixel cho lần chạy cuối.

## Scope

- `res/xml/locales_config.xml` (17 locale, Indonesian là `id`) + `android:localeConfig` trong manifest.
- `LocaleHelper`: API 33+ dùng `android.app.LocaleManager` làm nguồn sự thật, migrate locale cũ trong SharedPreferences đúng một lần (`Locale.Helper.Framework.Migrated`), map `in` ↔ `id`. API 25–32 giữ nguyên đường SharedPreferences.
- Không đụng ads/IAP/TalkBack/BUILD-003/signing.

## Root cause của 2 test instrumentation đỏ (BG6)

Lỗi nằm ở test, không ở production:
- `LocaleManager.applicationLocales[0]` trả `null` khi danh sách còn rỗng (NPE).
- Test đọc ngay sau khi ghi, không chờ framework (system_server) áp dụng.
- Lần chạy đỏ trên BG6 còn chỉ cài lại test APK, app APK cũ (hash `ea03…`) khác APK host (`1fd8…`), nên kết quả không đáng tin.

Sửa: `AppLanguageSettingsIntegrationTest` poll tối đa 5 s (`awaitFrameworkLanguage`), xác nhận `en` trước khi đặt `ja-JP`, cài đồng bộ cả hai APK.

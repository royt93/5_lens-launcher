# Audit DB-005 — openCount global nhất quán giữa các lens (2026-10-19)

## Thay đổi
- `AppPersistentDao.incrementAtomic`: lấy `MAX(OPEN_COUNT)` theo identifier, cộng 1, ghi cùng giá trị cho mọi row lens (`getMaxOpenCount` + `setOpenCountForAllLenses`). Trước đó `incrementExisting` cộng 1 cho từng row rồi `getOpenCount` chỉ đọc row `default`, nên in-memory của lens khác nhảy lùi theo số của default.
- `UtilApp.mergeLensPersistence`: lớp phủ `openCount` từ `getGlobalOpenCounts()` (một query `GROUP BY`), nên một lens chưa có row, hoặc row cũ bị lệch, vẫn thấy đúng số global. Sort theo số lần mở và Smart Focus (`SmartFocusArranger`) dùng cùng nguồn.
- Không đổi schema Room; `incrementExisting` và `getOpenCount` giữ lại (có test cũ `incrementExisting updates open count across all workspaces`).

## RED/GREEN
- RED (3 test, đỏ trên bản gốc): `incrementAtomic on a non-default lens never jumps back to the default lens count` (assert dòng 272), `mergeLensPersistence gives the same open count for the same app on every lens` (285), `a lens row created later starts from the global count instead of zero` (303).
- GREEN sau sửa. Integration trên Room thật: `openCountIsGlobalAcrossLensesAfterIncrementAppCount` (lens Work 50, default chưa có → bump ra 51 ở cả hai lens, merge cho cùng 51).
